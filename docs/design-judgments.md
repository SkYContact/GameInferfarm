# 设计判决（每条都有实测 why——勿凭直觉推翻）

> 来源：YGO 产线两夜 42→317-368 局/s（7.5-8.7×）的全部弯路沉淀。
> 环境：9955HX 16C/32T + 5070Ti Laptop。完整账本见 D:/ygo/.zcode/memory/
> inferfarm-handover.md §三 与 es-proving-ground-batch.md。

## 1. 到达层羊群：错峰是相位工程，不是 OS 问题
256 局同步起跑=灾难（69 局/s）。stagger 错峰=相位去同步；**fiber 下照样存在**
（不是 OS 抢占问题）。10ms 甜点；短作业 25ms 反噬。本库：`stagger_ms`（默认 10）。

## 2. SMT 是负资产
本负载 K=32/24 都比 K=16 差（lua 分支密缓存敏感）。工人默认=物理核
（hardware_concurrency/2）。**勿超物理核。**

## 3. 窗的真相：Windows 定时量子 ≈1ms
timeBeginPeriod(1) 下 cv 定时量子仍 ≈1ms——老路径"window 0.1" 实为 1ms。
银行调度台用 µs 精钟**忠实执行 0.1ms 会批量饿死 10×**。floor=0.2ms 实测最优
（0.15→127 / **0.2→129.6** / 0.25→127.6 / 0.3→124.6 / 1.0→100.4=旧路径平价点）。
本库：`window_floor`（默认 0.2，env FARM_BANK_WINDOW_FLOOR）。

## 4. 独车税：低负载下银行比内联慢
solo（单局）下银行慢 65%——每决策 1-2 个**线程唤醒量子**（工人睡了没人暖场）。
多线程满载整类成本消失（复活 0.12ms 实测）。纤程切换本身 ns 级。
混合规则（低负载内联发车+自旋）已设计未建（路线图项）。

## 5. 批的物理：每批固定门票
图回放每批 ~0.4ms 固定门票（kernel 发射+权重流 VRAM）**与行数无关**。
微批=为同一张图付全款；攒批大=每人多等窗（串行链付款）。银行=异步多批在飞
把门票重叠掉（gpu_flight 可 >100%）。

## 6. 调度台单线程
发车+收货+还池一人全包（完成序=投递序天然确定）。万批/s 量级（EPYC）时需分家
——已知扩容点，现在不分。

## 7. 图与地址一夫一妻
图回放烧死输入地址 → 每家银行一张专属预捕获图。真 free 银行会导致重新捕图
=灾难，所以"销毁"=归还预分配池（线性生命周期）。启动期图地址烧死小实验
（ProbeGraph）不过=拒绝银行制——字节安全性不赌。

## 8. 先占在途再领号（游标制）
领号=先 `inflight++` 占名额再 `cursor.fetch_add`——占额者必完工 ⇒ close-drain
等 inflight==0 时游标已终态，有效行=前缀连续 [0,n)。迟来残号由 state 复检拒绝，
虚增量在发车侧按作废槽跳过，账号自洽。

## 9. drain 有界：不写超时不写迁移
组装=同步纯计算无挂起点（GameAdapter 契约 1），在途写手必在几十 µs 完工。
close-drain 自旋等归零即可——超时/迁移路径是复杂度负债，明确不写。

## 10. 满座自驱发车
"满=人人写完"由 +1-先于-领号的构造成立。最后完笔者发现（游标满 && 在途归零）
就地发车，不等 timer 不经他人手。CAS 保证一家银行只发一次。

## 11. 只拷前 n 行
n>7/8·slots 走整块，否则逐输入前缀。第 n..slots 行图照读显存上批旧数据——
**行独立前提**下无害，每发车省 5.4MB→n×行宽 的 PCIe。

## 12. ORT 与 TRT 的分界（2026-09-22 追加）
- 调度/拷贝/攒批层收益**后端无关**（fiber 唤醒税、直写槽、批摊薄）——ORT 全额吃。
- 提交层（图合并 WDDM 提交、邮箱盖章去围栏）TRT 独有；ORT 有 enable_cuda_graph
  但绑线程（PerThreadContext 铁律）——银行会话全生命周期钉在调度台线程即合规。
- ORT 不暴露内部流 → 收割退回整设备同步（围栏税 ~0.4-0.5ms/批落在调度台线程，
  GPU 侧多批仍并行）。不赌 ORT 流序是纪律。
- refit 换心 TRT 独有；ORT 候选迭代=每腿重载会话（秒级）——演化场景选 TRT。
- 缺的实测点：**"ORT+银行制"的吞吐数**（账本里只有 ORT+线程 100 局/s 与
  TRT+银行 317-368 局/s 两端）——三后端接口就位后 A/B 交替 ≥4 腿补上。
